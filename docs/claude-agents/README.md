# Claude agent briefs

These files are short role briefs for Claude Code subagents working on riian gèng, the repo for helping learners learn spoken Thai through phonetic romanization before Thai script.

Stage as of 3 Oct 2026: validation and waitlist, not a full launch. The job is to learn whether real learners use the landing demo, return, or pay for the locked prices. Do not treat these files as permission to build every later product idea.

Claude Code should read briefs from this folder path:

```text
docs/claude-agents/
```

## Which brief to read

- `docs/claude-agents/learning.md`: Thai vocabulary, lessons, exams, certificates, and points.
- `docs/claude-agents/money.md`: Stripe, pricing, tax, and Pristine Mekong.
- `docs/claude-agents/growth.md`: unpaid posts, ads later, and first leads.
- `docs/claude-agents/social.md`: friends, usernames, and shared progress.
- `docs/claude-agents/code.md`: waitlist-to-paid engineering order and post-PMF points holes.
- `docs/claude-agents/waitlist-email.md`: waitlist capture and email delivery.

If another repo doc conflicts with these briefs, prefer the facts in this folder for work scoped to validation and waitlist.
